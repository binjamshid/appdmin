# Changelog

All notable changes are documented here. This project follows semantic versioning.

## 2.0.0 - Unreleased

- Rebuilt the application as the Appdmin FOSS capability kernel.
- Added encrypted database configuration and an adapter-owned product catalog.
- Added sandboxed, manifest-scoped Deno adapters and a public adapter SDK.
- Added bundled App Store Connect, OpenAI, Anthropic, Gemini, OpenRouter, and OpenAI-compatible
  adapters.
- Added real App Store Connect daily Summary Sales Report ingestion with signed units, per-currency
  estimated proceeds, report provenance, and explicit unavailable states.
- Added a resumable five-step GUI onboarding flow and capability-aware responsive application shell.
- Added the `appdmin` CLI plus Docker Compose and systemd installation targets.
- Removed all portfolio-specific products, collectors, hostnames, schemas, and deployment
  assumptions.
